# Bundled PDF fonts

Noto Sans Devanagari from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/notosansdevanagari

The regular and bold static fonts were instantiated from
`NotoSansDevanagari[wdth,wght].ttf` at width 100 and weights 400/700
using fontTools 4.67.0. Downloaded 2026-10-18. Latin glyphs are retained
so report names and measurement units share the same shaping engine.
The original SIL Open Font License is included in OFL.txt.
fontTools is a font preparation tool, not an application runtime dependency.
